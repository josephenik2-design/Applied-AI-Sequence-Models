# Applied AI: Poetry Generation with LSTMs & Transformers

**Author:** Joseph Eniola Kehinde  
**Context:** MSc in Trusted AI for Blockchain System Southern Federal University  
**Relevance:** Foundational sequence modeling architectures (LSTM, Attention, Transformers) with direct applicability to 3D Computer Vision and action recognition.

##  Project Overview
This repository contains the PyTorch implementation of three generative AI architectures:
1. **Character-Level LSTM** – Demonstrates overfitting and memorization.
2. **Word-Level LSTM with Attention** – Shows improved coherence and context.
3. **Transformer Multi-Head Attention** – Core building block for Vision Transformers (ViT) used in 3D point clouds.

##  Comparative Results
| Metric | Char-LSTM | Word-LSTM+Attention |
| :--- | :--- | :--- |
| Grammar | Medium | High |
| Semantics | Low | Medium |
| Overfitting | Severe | Reduced |
